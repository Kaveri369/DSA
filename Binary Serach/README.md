# 🔍 Binary Search — DSA

A structured collection of Binary Search problems solved in C++,
following **Striver's A2Z DSA Sheet**.

This repository focuses on mastering Binary Search patterns,
optimizing problem-solving skills, and building strong
algorithmic foundations for technical interviews.

---

## 🎯 Objectives

- Master Binary Search from basics to advanced problems.
- Understand searching in sorted and rotated arrays.
- Learn Binary Search on Answer.
- Improve time and space complexity analysis.
- Prepare for product-based company interviews.

---

## 📚 Topics Covered

### 1️⃣ Binary Search Basics
- Binary Search on 1D Arrays
- Lower Bound
- Upper Bound
- Search Insert Position
- Floor and Ceil

### 2️⃣ Binary Search on Arrays
- First and Last Occurrence
- Count Occurrences
- Search in Rotated Sorted Array
- Find Minimum in Rotated Sorted Array
- Single Element in a Sorted Array

### 3️⃣ Binary Search on Answer
- Square Root of a Number
- Nth Root of a Number
- Koko Eating Bananas
- Minimum Days to Make M Bouquets
- Capacity to Ship Packages
- Aggressive Cows
- Allocate Books

### 4️⃣ Advanced Problems
- Median of Two Sorted Arrays
- Kth Element of Two Sorted Arrays
- Split Array Largest Sum
- Minimize Maximum Distance

## ⏱️ Complexity Analysis

| Algorithm | Time Complexity | Space Complexity |
|-----------|----------------|------------------|
| Linear Search | O(N) | O(1) |
| Binary Search | O(log N) | O(1) |
| Recursive Binary Search | O(log N) | O(log N) |
