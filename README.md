# 🔥 Problem-Solving Rule

For every problem:

1. Understand the problem
2. Write brute force
3. Analyze complexity
4. Find the bottleneck
5. Optimize
6. Identify the pattern
7. Code yourself
8. Test edge cases
9. Analyze TC + SC
10. Add the problem to revision list

### ❌ Don't do this

```text
Watch solution
↓
Copy code
↓
Mark problem solved
```

### ✅ Do this

```text
Problem
↓
Think 20–30 min
↓
Brute Force
↓
Optimize
↓
Hint if needed
↓
Understand solution
↓
Close solution
↓
Code yourself
↓
Re-solve later
```
