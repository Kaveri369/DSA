# 🧪 HOW TO SOLVE EVERY PROBLEM

## 30-Minute Rule

### 0–5 min

Understand the problem.

### 5–15 min

Find brute force.

### 15–25 min

Try to optimize.

### 25–30 min

Use a hint if genuinely stuck.

Then:

```text
Understand Solution
        ↓
Close Solution
        ↓
Code From Scratch
        ↓
Test Edge Cases
        ↓
Write TC + SC
        ↓
Add Pattern
```
